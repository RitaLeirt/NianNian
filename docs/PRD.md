## 2. 产品概述

### 2.1 定位
念念是一个**本地优先的个人「外部前额叶」**：替你记着那些悬而未决、常卡在别人手里（或单纯被你遗忘）的事，在合适的时候提醒你**该推进什么、以及该怎么说**。

它不追求成为又一个塞满清单的待办 App，而是只盯一类事——**悬念事项（Suspense Item）**：一件事卡在中间，等待某一方（你 / 对方 / 双方）推进，不推进就会凉。

### 2.2 产品隐喻
念念被具象成一只「值夜书房猫」——安静、克制、不抢注意力，但会在该提醒时轻轻冒泡。核心意象是一枚**毛线球 🧶**，代表「球在谁手里（ball in court）」这个贯穿全产品的判断。

### 2.3 核心理念信条
> **凡是需要理解模糊语言的，交给 AI；凡是需要保证可靠、不出幺蛾子的，交给规则。**

- 下一步判断、排序、提醒时机：**确定性规则推算**，不靠 AI 自由发挥（可复现、不抽风）。
- AI 只接手规则搞不定的部分：读懂口语化指代、把话术说得更得体。且 AI 输出永远是**草稿或建议**，决定权永远在用户。

## 3. 目标用户与场景

### 3.1 用户画像（进度责任人）
他们的工作大量由「等别人动」或「等自己动手」推进，自己 juggle 多件悬事。

| 画像 | 典型悬念 | 念念帮到什么 |
|---|---|---|
| 做销售的她 | 报价发出去客户静默 | 记着「凉了几天」，到点提醒催；备好一句温和催收话术 |
| 自由设计师 | 交稿等尾款，不好意思天天问 | 给一句得体的催收话术，该开口时推一下 |
| 做运营的他 | 跨部门事卡在中间谁也不动 | 标出「双向卡住」，提醒拉短会拍板 |
| 自由创业者阿禾 | 报税、域名续费、自我复盘，没有对接人 | 不追问「对方是谁」——没对方就记成自我提醒，一样到点 |

### 3.2 使用场景
- **临时记一笔**：正在开会 / 聊天，冒出一件悬事，一句话丢给念念，继续手头工作。
- **每天开始 / 收尾**：打开看板看「今日」该推什么，推进后打卡。
- **要开口了**：面对一件凉了的事，不知道怎么措辞，用话术库生成一句能直接发的话。
- **周复盘**：一键把本周动作揉成一段可复制的周报 / 日记。

## 4. 要解决的问题（痛点）

1. **悬念散落**：等回复、等确认、等对方动作的事，散落在脑子、聊天记录、便利贴里，没有统一归口。
2. **容易凉**：对方静默时，人不会主动想起来「该催了」，直到 deadline 撞上才慌。
3. **不会开口**：知道该跟进，但措辞别扭、怕得罪人，于是拖延，事更凉。
4. **待办 App 不区分责任方**：通用待办把「我该做的」和「等别人做的」混在一起，看不到「球在谁手里」，自然也就不知道该催还是该自己动手。
5. **被工具绑架**：很多效率工具本身要养（打卡、养成、复杂配置），反而增加负担。

---

## 5. 产品原则

1. **本地优先，数据自有**：数据存在用户自己的环境（SQLite 文件 / 用户的工作区），免费、开源、可导出，不被平台锁死。
2. **规则优先，AI 可选增强**：核心推进逻辑确定性可复现；AI 是增强而非地基。
3. **用户永远有决定权**：所有 AI 输出先给你看、你确认才生效；悬念判重、话术、日记摘要皆是草稿。
4. **陪伴不绑架**：桌宠是一个更顺手的入口，**不是需要喂养/升级的宠物**——不占额外注意力。
5. **录入极简**：用户唯一必填的是那句原话，其余由念念解析/推断/默认，用户只做「确认或改」。
6. **好看但从不喧宾夺主**：日光风、纸感、鼠尾草绿，克制的微交互。

## 6. 核心机制

### 6.1 球的隐喻（Ball in Court）
全产品最核心的判断，用一枚毛线球说清「下一步该谁动」：

| 状态 | 含义 | 视觉 |
|---|---|---|
| 球在我方（mine） | 该我动手推进 | 实心毛线球 + 猫爪 |
| 球在对方（theirs） | 在等对方回复 / 确认 / 动作 | 远处绿毛线球 |
| 双向卡住（stuck） | 双方都没动，卡在中间 | 缠绕乱线 |

没有对接人的事，球默认在你自己爪边——没人替你把球接走，所以这是你自己的事。

### 6.2 push 闭环（念念主动）
```
记一笔 → 念念盯着 → 到点提醒（附话术）→ 你确认
```
1. **记一笔**：一句话说清，念念用确定性规则先猜一版（谁该动 / 对方 / 在等 / 下一步 / DDL / 优先级）。
2. **念念盯着**：按确定性规则推算紧急度，不靠 AI 瞎猜。
3. **到点提醒**：凉够了或快逾期，桌宠主动冒泡，并先给一句能直接发的话。
4. **你确认**：你把话发出去后回来点「确认／推进」，凉的天数才清零——**不是看到弹窗点一下就算完事**。

### 6.3 pull 视角（用户主动俯瞰）
三视图看板，看「哪些事、排在前面的什么」由系统算好，用户不用自己拖：
- **今日**：今天非动不可的球（逾期、到点、卡住）。
- **本周**：今日的超集 + 凉够两天、七天内到期的。
- **全部**：所有还悬着、没放下的事。

### 6.4 紧急度推算（确定性）
排序由系统按确定性规则计算，综合维度包括：**凉置天数 × 权重＋责任方权重（我方/卡住更高）＋优先级权重＋DDL 临近梯度（逾期＞今日＞2 天内＞7 天内）**。规则可复现，不随机。

## 7. 功能需求详述

### 7.1 记一笔 · 半展开解析
- **用户目标**：用最少的输入，可靠地记下一桩悬事。
- **行为**：
  - 顶部输入框写一句话（如「报价后客户静默」），回车触发**半展开解析浮层**。
  - 念念用确定性解析器（`/api/parse`）先猜：球在谁手里、对方、在等什么、下一步、DDL、优先级。
  - 用户瞄一眼，猜错当场改（下拉/输入），点「确认并添加」。
- **录入红线**：唯一必填是「原话 / 标题」，其余字段解析可改、或全默认。
- **关键规则**：若提到人名，该人名自动归档为对接人（同名自动复用）。

### 7.2 事项看板
- **用户目标**：一眼看今天/本周/全部该推什么，按需筛选。
- **行为**：
  - 三视图切换（今日 / 本周 / 全部），卡片自动按紧急度排序。
  - 筛选：按紧急程度（该动 / 在等 / 卡住）、按沟通对象、按视图模式（卡片 / 列表 / 日历，看的方式用户选）。
  - 搜索：跨事项、人名、进展全文搜索。
  - 每条卡片可：推进（push，清零凉的天数）、完成（complete）、先放一放（hold，临时抑制期）、编辑、删除、恢复。
- **关键规则**：完成/推进动作自动写入日记本（见 7.6）。

### 7.3 话术 / 提示词库
- **用户目标**：需要开口时，有现成、得体、可套用的话。
- **内容**：
  - **内置示例库**：销售 / 自由职业 / 运营 / 通用四套预置话术（每个工作区首次访问自动种入，保证打开即有）。
  - **自定义模板**：用户自建，按 行业 / 语气 / 场景 / 目的 多维度打标，支持搜索与筛选。
  - **既是话术也是提示词**：每条模板含「话术正文」（带 `{对方}{在等}{事}` 占位，套用时实时替换）与「天蝎提示词」（给 AI 的更全上下文，说明背景/人设/目的/语气）。
- **交互**：卡片下方直接展示「套用后的示例效果」，不是盲选；可一键存给某位对接人。

### 7.4 话术渲染（生成一句话术）
- **用户目标**：针对某件具体的事，得到一句能直接发出去的话。
- **行为**：在事项上点「生成话术」→ 选模板 → 系统用该事项的对方/在等等字段替换占位符，产出成品文案，可复制。
- **对应接口**：`POST /api/render`。

### 7.5 沟通对象（对接人管理）
- **用户目标**：记熟常对接的人，以及该怎么跟他们说话。
- **内容**：姓名、职业/角色、上下游关系（上游/下游/平级/外部）、人设（可选，让话术更准）、与该人的对接话术列表。
- **行为**：
  - 记一笔中提及的人名**自动归档**为对接人，同名归同一人。
  - 对接人详情抽屉可查看，并「从话术库挑一句」存为该人的对接话术。
  - 反向也可：从模板「存给哪位对接人」。

### 7.6 日记本
- **用户目标**：留存每一件事的来龙去脉，便于复盘。
- **内容**：
  - **自动沉淀**：记一笔 / 推进 / 完成 / 恢复 等每个动作自动写入日记（按天归档、可搜索）。
  - **一键周报 / 本周日记**：把本周动作揉成一段可复制的摘要（`/api/journal/weekly` 或顶栏「一键周报」）。
- **价值**：日记本是「留存命门」——即使事项关掉，脉络仍在。

### 7.7 桌宠猫（陪伴与入口）
- **用户目标**：一个不打扰、但顺手的提醒入口。
- **行为/状态**：
  - **常驻浮层**（右下角）：可拖拽移动。
  - **撸猫**：点击涨亲密度（`/api/pet/pet`）。
  - **冒泡提醒**：有该推 / 快逾期的事，猫主动跑过来冒泡（文案口吻遵循 7.10 的语气设置）。
  - **悬停喂一笔**：桌面端悬停展开输入框，直接对猫说一件悬事；也支持丢一张截图（图片喂猫，见 13 章规划）。
  - **随时可关**：设置里一键关闭，浮窗整体消失。
- **原则**：不设亲密值、不喂养、不升级——只是更顺手的入口。

### 7.8 定时任务
- **用户目标**：把念念的「主动」落成确定性的定时触发——到点自己动，而非 AI 随机冒泡。
- **内容**：任务名、执行频率（工作日 / 每天 / 每周一 / 每周五）、执行时间、到点生成的事（标题模板，支持 `{周报}{日期}` 占位）、启用/禁用。
- **行为**：到点后按「生成的事」模板建一条悬念事项，之后与手动记的事**走同一套盯事规则**——不会因来自定时任务就瞎催。
- **实现边界**：任务配置与生成逻辑已实现；自动触发依赖部署环境的定时任务能力（如 Vercel Cron），见第 11 章与 13 章。

### 7.9 账户与令牌（多工作区隔离）
- **用户目标**：一份隔离、可切换、可重置的工作区数据。
- **机制**：一个 token = 一个工作区 = 一份隔离数据。所有用户数据表均带 `owner` 列，按 token 过滤读写。
- **行为**：
  - 首次打开默认进入演示工作区 `demo-default`（已预置完整示例数据，打开即有内容）。
  - 可查看当前 token、给工作区命名、重新生成 token（旧 token 失效，数据仍归属该工作区）。
  - 签发新工作区时立即预填示例数据（事项/对接人/日记/计划/桌宠/话术库均非空）。

### 7.10 宠物设置（皮囊）
- **用户目标**：把念念调成「自己的猫」。
- **已实现项**：
  - 桌宠显示开关（关掉后常驻猫躲起来）。
  - 名称（小名）。
  - **互动语气**：温柔陪伴 / 极简高效 / 俏皮毒舌——**真实改变所有冒泡文案口吻**，非摆设。
- **规划项**：形象自定义（换皮/皮肤）当前仅默认猫可用，其余皮肤为「待解锁」（P2 后期）。

### 7.11 搜索 / 统计 / 归档
- **搜索**：跨事项、人名、进展的全文检索（`/api/search`）。
- **统计**：看板维度的计数与概览（`/api/stats`）。
- **归档**：已完成/已放下事项的历史归档查看（`/api/archive`）。

### 7.12 AI 来源设置（占位）
- 当前为**占位形态**：提供「本地规则（当前演示版）/ 自带 API Key（BYO）/ 本地模型（Ollama）」的选项框架，**真实 AI 尚未接入**，当前演示版用本地规则模拟解析与话术。
- 失败回退策略已定义：模型不可用时自动回退本地规则，保证离线也能跑。

## 9. 数据模型

所有用户数据按 `owner`（工作区 token）隔离。核心表：

| 表 | 作用 | 关键字段 |
|---|---|---|
| `auth_tokens` | 工作区令牌 | token / label / created_at / last_used |
| `items` | 悬念事项 | title(必填) / who(mine·theirs·stuck) / person / waiting / next_step / ddl / priority / important / hold_until / done |
| `templates` | 话术/提示词库 | name / industry / tone / scene / purpose / body(占位) / scorpion(AI上下文) / builtin |
| `colleagues` | 对接人 | name / role / relation(upstream·downstream·peer·external) / persona |
| `contact_scripts` | 对接人话术 | colleague_id / 引用模板或自定义正文 |
| `journal` | 日记本 | kind(note·push·done…) / text / created_at |
| `schedules` | 定时任务 | name / freq / time / template / enabled |
| `pet` | 桌宠状态 | intimacy / x / y / name / tone / skin |

> 录入红线：用户唯一必填仅 `items.title`（原话）；`who/person/waiting/next_step/ddl/priority` 由解析器抽取、可改；`cold_days/status/done` 自动算。

## 10. 设计系统（简述）

引用原型文档 `prototype.html` 中的完整定义，要点：

- **风格**：日光风、纸感卡片、鼠尾草绿点缀、一枚毛线球图标——好看但从不喧宾夺主。

## 11. 技术约束与架构

- **前后端一体、零 npm 依赖**：后端 Node 22 `node:http` + `node:sqlite`；前端原生 HTML/CSS/JS，无构建工具。
- **本地优先**：数据落地 SQLite（`data/niannian.db`）；Vercel 等 Serverless 环境落到 `/tmp`（冷启动间不保证持久，但每次重建库会自动重新种入示例数据）。
- **多工作区隔离**：token 即 owner，所有读写按 owner 过滤。
- **部署**：作为 Vercel Serverless Function（`api/index.js` 为 catch-all handler，由 `vercel.json` rewrites 转发所有请求），需 Node 22.5+ 且启用 `node:sqlite`（`NODE_OPTIONS=--experimental-sqlite`）。
- **已实现的解析/话术为确定性规则引擎**，未接入 NLP/LLM（见 7.12、13 章）。

---

## 12. 非目标（Non-goals）

凡是让「记事更可靠、更省力」的，优先级永远高于让「猫更可爱」的。明确不做：

1. 不做塞满一切的待办 App，只盯**悬念事项**。
2. 不做真·系统桌面挂件，就是网页里的交互猫。
3. 看板不做自定义拖拽排序 / 复杂甘特（顺序由系统算）。
4. 话术不强制建「同事画像库」（人设可选填）。
5. 判断下一步不靠 AI 自由发挥（规则优先）。
6. 不绑定平台、不锁数据（本地优先、可导出）。

## 13. 当前已实现范围 vs 规划中

### 已实现（MVP · 当前可运行）
- 记一笔 + 确定性半展开解析；事项看板三视图 + 筛选 + 卡片/列表/日历视图切换；球三态。
- 话术/提示词库（内置四套示例 + 自定义）+ 话术渲染。

### 规划中 / 占位（未实装，需后续迭代）

## 14. 成功衡量（建议指标，供后续迭代参考）

- **激活**：首次打开后 24h 内记下 ≥1 笔悬念事项的比例。
- **推进确认率**：被提醒（push）的事项中，用户回来点「确认/推进」的比例（衡量提醒有效性）。
- **话术使用率**：生成话术并被复制/采用的比例。
- **留存**：周度回访与「本周日记」生成次数。
- **陪伴但不打扰**：桌宠关闭率（若过高说明打扰）。

## 15. 变更清单（v1.0 → v1.2）

### v1.2 · 2026-08 · UI/UX 打磨 + 对接人协作强化

**AI 全链路可用**
- 4 处 AI 功能全部接入统一 `callAI(owner, sys, user)`：语义解析 · 一键周报 · 模板话术生成 · 推一下自动话术
- 填写 API Key 时自动切换来源到 BYO，避免用户漏切
- AI 未启用 / 调用失败会在气泡内明确显示原因并提供"去开启 AI"直达链接

**推一下自动话术（POST /api/scripts/auto）**
- 结合事项本身（对方/在等/下一步）+ 对接人偏好话术 + 匹配场景模板三层上下文
- 有 AI 就让 AI 综合三层生成一句可复制话术；无 AI 则回退到已存偏好 / 场景模板 / 兜底文案
- 桌宠气泡"推一下"和看板卡片"推进一步"均触发此流程

**看板"推进一步"改流程**
- 从"立即调 push API"改为"先弹话术生成窗口"
- 窗口含"复制 · 换一句"和底部 `先放一放 / 推进一步 / 打卡完成` 进度按钮
- 操作后自动关闭并同步看板

**对方字段模糊匹配**（三处添加入口统一）
- 记一笔 · 编辑事项 · 桌宠一句话添加，全部支持从已有对接人下拉选择
- 输入新名字时三级模糊匹配：大小写忽略 → 子串包含 → 编辑距离 ≤1
- 相似但不同名时弹确认框，让用户选"用已有"或"新建"

**日记时区修复**
- 种子 `wd()` / `at()` 改用 CST 意图（Vercel UTC 服务器也能正确显示为北京时间）
- `Journal.list()` 过滤未来时间戳，防止历史数据错位显示为未来记录

**响应式重构**
- ≤980px：侧栏折叠为顶栏 + 固定底部 6-tab 导航（图标+文字，横向可滚，永远可见可点）
- ≤900px：看板筛选竖排堆叠、seg 内子按钮全宽
- ≤600px：卡片单列 · 弹窗改底部抽屉 · 桌宠气泡自适应屏宽
- ≤380px：品牌文字隐藏、看板标题瘦身

**设计系统打磨**（对齐 frontend-design-pro 规范）
- Focus 环从琥珀 amber 改为主色 sage，加 3px 半透明光晕
- 圆角规范化到 8/16/24/999 网格
- Hover 底色改用暖色浮层（rgba(127,160,133,x)），不再用纯黑叠加导致的暖纸面发脏
- 侧栏计数徽章重做：暖色底 → 选中态覆盖为 sage 实底 + 白字（原本白色透明底几乎不可见）
- 全站细滚动条主题（8px 暖色）
- 品牌标题 letter-spacing 从 1px 降到 0.4px（中文更紧凑）
- 表单 focus 均加 3px sage 半透明光晕

**Vercel 部署适配**
